# История версий

## 1.5

### Единый каталог моделей всех CLI
- `ModelCatalogService` в демоне собирает модели Claude (встроенный список, алиасы `opus`/`sonnet`/`haiku`, модели из `~/.claude/settings.json`), Codex (`~/.codex/models_cache.json` и `config.toml` с уровнями рассуждений) и Antigravity (`agy models` с кешем и очисткой ANSI, метаданные `~/.gemini/antigravity/`). Каталог приходит в офис при подключении и по событию `models:updated`; доска задач берёт модели из него же.
- Вместо ручного ввода модели — селектор с группами «Claude Code / Codex / Antigravity», подписями и возможностями моделей. Выбор модели из сводного каталога подставляет провайдера, список уровней рассуждений подстраивается под модель. Кнопка ↻ пересканирует CLI. «Указать кастомный ID модели…» — последний пункт списка; демон принимает такой ID только как простой идентификатор.

### Сотрудники и конструктор агента
- Кастомные сотрудники по схеме CrewAI: роль, цель, характер и опыт, формат результата; модель и уровень рассуждений, доступ, внешность (цвет одежды и аксессуар с живым превью), набор MCP и «Тонкие настройки работы»: стиль мышления, бюджет контекста и стратегия переполнения, автоповторы, тайм-аут шага, разрешённые и исключённые пути, флаги CLI только из списка разрешённых.
- Новая вкладка «Сотрудники»: карточки с цветом провайдера, ролью, моделью и уровнем, индикатором MCP, раскрывающимся характером и действиями «Поручить задачу», «В команду», «Изменить», «Дублировать», «Экспорт». Клик по карточке показывает сотрудника на сцене. Профили хранятся в `~/.land/agents.json`.

### Переговорка: команды как граф состояний
- Четыре режима: последовательный конвейер, цикл автор → критик → редактор до `APPROVED` (1–5 итераций), параллельный консилиум с синтезатором и автономный тимлид, который делит задачу, раздаёт подзадачи специалистам и собирает итог.
- Каждый шаг выдаёт типизированный артефакт (`ArchitectureSpec`, `ImplementationDiff`, `VerificationReport`, `SecurityAudit`, `ChapterOutline`, `ChapterDraft`, `ContinuityAndLogicCritique`, `StylisticPolishedManuscript` и др.). Следующий шаг получает размеченный конверт с артефактами как данные и проверяет его; пустой или явно неполный артефакт останавливает команду.
- Неизменяемый якорь (паспорт мира, глоссарий, инварианты API) передаётся каждому шагу.
- Контрольная точка после каждого шага: упавшую, остановленную или прерванную перезапуском демона команду можно продолжить с нужного шага, при желании сменив модель и даже CLI этого шага; готовые шаги не перезапускаются.
- Большие артефакты (глава 15 000+ символов) передаются файлом в `<проект>/.land/artifacts/<запуск>/` (папка исключена из git), чтобы текст доходил до следующего агента целиком.
- Автоповторы с экспоненциальной паузой и тайм-аут шага из тонких настроек. Пресеты команд: «Книжное бюро», «Конвейер кода», «Консилиум», «Автономный тимлид» и свои, сохраняемые в `~/.land/presets.json`.
- Над работающим участником команды на сцене — баббл с этапом («Пишет главу…», «Проверяет логику…», «Вносит правки…»), передача хода показывается анимацией.

### Настройки, MCP и Doctor
- Вкладка «Настройки» (и кнопка ⚙ в шапке): тема, масштаб интерфейса, 30/60 FPS и энергосбережение в фоне, режим жителей офиса, звук и браузерные уведомления о завершении; пути CLI с ручным переопределением; стек MCP; лимит одновременных задач (1–8), папка артефактов, лимит захвата вывода CLI (200 000–2 000 000 символов); безопасность и хранилище.
- Четыре MCP применяются к каждой задаче и каждому шагу команды: `markitdown` (вложения .docx/.pdf/.epub/.xlsx/.html/.md/.txt в Markdown), `context-budget` (подсчёт символов и токенов, шкала контекста в разговоре), `strategic-compact` (сжатие промежуточного контекста с сохранением имён, заголовков и сигнатур), `agentic-shield` (блокировка опасных команд и выхода за папку проекта, маскирование ключей, пометка косвенных prompt injection). Меню MCP в шапке показывает статус и ставит недостающее в один клик; свои три MCP ставятся офлайн в `~/.land/mcp-runtime/`, MarkItDown — из PyPI по запросу.
- «Проверить систему» (Doctor): Node.js, права на `~/.land`, каждый CLI, каталог моделей, MCP, свободное место, доступность сервисов провайдеров — с кнопкой «Исправить автоматически» там, где это возможно. Тот же отчёт: `node apps/daemon/src/doctor.ts`.
- Резервная копия `land-backup-v1.5.json`: настройки, сотрудники, пресеты и метаданные разговоров. Импорт не меняет локальные пути к CLI.

### Разговоры
- Переименование и закрепление разговоров, экспорт всей истории в Markdown. Шаги команды подписаны названием команды и шага.

### Надёжность и безопасность
- Сессионный токен демона: WebSocket и HTTP без токена отклоняются (кроме `/health` и хуков), офис получает токен только с разрешённого адреса; токен можно сменить из настроек.
- Атомарная запись всех файлов `~/.land/` (временный файл и переименование, очередь записи) с копией `.bak` и восстановлением повреждённого JSON при запуске.
- `ProcessSupervisor` завершает всё дерево процессов CLI при отмене, остановке команды и выходе демона (`taskkill /T /F` на Windows); частичный ответ сохраняется.
- Обход `C:\Program Files\WindowsApps` при `spawn EPERM`, запуск npm-пакетов через Node.js, пути с пробелами и кириллицей только массивом аргументов.
- Очистка ANSI в выводе всех CLI; понятные сообщения об истёкшем входе и исчерпанном лимите запросов.
- DNS: чтение всех адаптеров (Ethernet, Wi-Fi, VPN и виртуальные) на русской и английской Windows в UTF-8, проверка адресов IPv4/IPv6.

### Интерфейс
- Входящие обновления больше не пересоздают формы: кнопки, поля ввода, открытые списки и раскрытые блоки сохраняются, фокус и курсор не теряются во время стриминга.
- Шапка помещается на экране телефона; общие элементы (селектор моделей, модальные окна, бейджи, уведомления) вынесены в `ui-kit.ts`.

## 1.0

Первый выпуск land.inc — локального офиса AI-агентов.

- Изометрический офис, квартал и сад; наблюдение за Claude Code, Codex и Antigravity.
- Задачи, продолжение сессий и совместная работа с явным выбором планировщика и проверяющих.
- Запуск Codex и Claude из npm на Windows без прямого исполнения скриптов-обёрток.
- Инструкции установки CLI и повторная проверка доступности.
- Вкладка DNS: чтение адаптеров Windows, ручные IPv4/IPv6, проверки, UAC, резервная копия и восстановление.
- Обновление из интерфейса: посылка у входа, описание релиза, отдельная установка, проверки и возврат к прежней версии при сбое запуска.
- GitHub Releases с версиями x.y и тегами vX.Y.

Для запуска нужны Node.js 24+, npm и Git. Авторизованный CLI нужен только для задач соответствующего агента. Установка из интерфейса работает при запуске через `npm run dev`.

Antigravity остаётся экспериментальным. Изменение реальных DNS через UAC не выполнялось при тестировании выпуска: применение и восстановление проверены на тестовом адаптере и с подменой системных операций.
