# История версий

## 1.0

Первый выпуск land.inc — локального офиса AI-агентов.

- Изометрический офис, квартал и сад; наблюдение за Claude Code, Codex и Antigravity.
- Задачи, продолжение сессий и совместная работа с явным выбором планировщика и проверяющих.
- Запуск Codex и Claude из npm на Windows без прямого исполнения скриптов-обёрток.
- Инструкции установки CLI и повторная проверка доступности.
- Вкладка DNS: чтение адаптеров Windows, ручные IPv4/IPv6, проверки, UAC, резервная копия и восстановление.
- Обновление из интерфейса: посылка у входа, описание релиза, отдельная установка, проверки и возврат к прежней версии при сбое запуска.
- GitHub Releases с версиями x.y и тегами vX.Y.

Для запуска нужны Node.js 24+, npm и Git. Авторизованный CLI нужен только для задач соответствующего агента. Установка из интерфейса работает при запуске через `npm run dev`.

Antigravity остаётся экспериментальным. Изменение реальных DNS через UAC не выполнялось при тестировании выпуска: применение и восстановление проверены на тестовом адаптере и с подменой системных операций.
