# land.inc

2.5D офис для AI-агентов (вид сверху). Агенты ходят по офису, сидят за компьютерами, общаются друг с другом,
а офис живёт синхронно с реальными сессиями **Claude Code / Claude Desktop** и **Codex**, которые запущены на этом компьютере.

Никаких API-ключей: офис только читает локальные файлы, которые агенты и так пишут на диск.

## Запуск

Нужен Node.js 24+ (демон запускается из TypeScript без сборки).

```bash
npm install
npm run dev        # демон + офис → http://127.0.0.1:5173
npm run dev:demo   # то же самое плюс демо-агенты, которые проходят по всем зонам
```

## Как работает синхронизация

| Источник | Где лежит | Что даёт |
|---|---|---|
| Claude Code (CLI, IDE, вкладка Code в Claude Desktop) | `~/.claude/projects/<project>/<session>.jsonl`, сабагенты в `<session>/subagents/*.jsonl` | Транскрипт в реальном времени: промпты, ответы, вызовы инструментов, `stop_reason` |
| Codex (CLI и Codex Desktop) | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` + индекс тредов в `~/.codex/state_*.sqlite` | Сообщения, вызовы команд, `task_complete`, запросы разрешений |
| Хуки Claude Code (опционально) | `~/.claude/settings.json` | Мгновенный сигнал «ждёт вашего разрешения» (`Notification`) |

`apps/daemon` опрашивает эти файлы, читает только дописанные байты и превращает записи в общий поток событий
(`packages/protocol`). Клиент `apps/office` получает его по `ws://127.0.0.1:4317`.

Демон слушает только loopback и отклоняет браузерные запросы с не-localhost `Origin`, чтобы посторонний сайт
не мог прочитать транскрипты.

Треды, которые Codex Desktop импортировал из других агентов, скрываются: такой файл записан целиком за миллисекунды.
Если продолжить импортированный тред в Codex, его агент появится в офисе.

### Хуки для мгновенных статусов (опционально)

Без хуков «ждёт разрешения» определяется эвристикой: вызов инструмента висит дольше 12 секунд без результата.
С хуком Claude сразу сообщает об этом офису. Добавьте в `~/.claude/settings.json`:

```json
{
  "hooks": {
    "Notification": [
      { "hooks": [{ "type": "command", "command": "curl -s -m 1 -X POST --data-binary @- http://127.0.0.1:4317/hook || true" }] }
    ]
  }
}
```

Демон также понимает `UserPromptSubmit`, `PreToolUse`, `PostToolUse` и `Stop` на том же адресе.

## Что видно в офисе

- **Сессия = сотрудник.** Цвет рубашки: оранжевый у Claude, зелёный у Codex, фиолетовый у демо-агентов.
  Сабагенты поменьше и связаны с родителем пунктиром.
- **Проект = ряд столов.** Сессии одного репозитория садятся рядом.
- **Действие → место:**

| Активность | Инструменты | Где агент |
|---|---|---|
| думает / пишет код | reasoning, `Edit`, `Write`, `apply_patch` | свой стол (монитор синий / зелёный) |
| читает | `Read`, `Grep`, `Glob`, `cat`, `rg`, `git log`… | архив |
| запускает команды | `Bash`, `PowerShell`, `shell` | серверная (стойки мигают) |
| ищет в сети | `WebSearch`, `WebFetch`, браузер | интернет-киоски |
| планирует | `TodoWrite`, `update_plan` | доска планов |
| делегирует | `Agent` / `Task`, `spawn_agent` | переговорка |
| ждёт вас | запрос разрешения, вопрос | свой стол, поднятая рука и «!» |
| закончил ход | `end_turn`, `task_complete` | кухня |

Сессия без активности 45 минут уходит домой через дверь. Клик по агенту или строке в списке показывает журнал
его последних действий. Камера: перетаскивание, колесо мыши для зума, двойной клик возвращает общий вид.

## Структура

```
apps/daemon        # наблюдатель за файлами + WebSocket-сервер (Node, TypeScript без сборки)
  src/adapters/    # claude.ts, codex.ts — разбор форматов каждого агента
  src/store.ts     # состояние агентов и переходы по времени (простой, ожидание, уход)
apps/office        # клиент на PixiJS: изометрическая сцена, агенты, боковая панель
packages/protocol  # общие типы событий
```
