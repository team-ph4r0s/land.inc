> [!IMPORTANT]
> **Zero-Cloud & 100% Local Privacy:** land.inc не отправляет ваш исходный код, промпты или транскрипты в облачные сервисы land.inc. Демон слушает исключительно локальный адрес `127.0.0.1`, соединение защищено криптографическим сессионным токеном демона. Обращения к моделям выполняются напрямую через ваши локально установленные и авторизованные CLI с соблюдением системных песочниц. Комплекс **Agentic Shield** гарантирует санитизацию путей, блокирует Prompt Injection и маскирует любые секреты (`[REDACTED_BY_AGENTIC_SHIELD]`).

## 🚀 Зачем это нужно

Когда разработчик запускает несколько AI-ассистентов в параллельных вкладках терминала или разных проектах, контекст мгновенно теряется. Непонятно, кто завис на подтверждении команды, кто закончил прогон тестов, а кто исчерпал лимит контекста.

**land.inc** собирает разрозненные процессы в единое наглядное рабочее пространство:

* 🏢 **Панорамный обзор офиса:** активные сессии сгруппированы по рабочим столам проектов; наглядно видно текущее действие (думает, пишет код, читает архив, запускает команды в серверной).
* 🔍 **Контекст в один клик:** выбор любого персонажа на сцене открывает хронологический журнал его ходов, вызовы инструментов и результаты выполнения.
* 📋 **Интерактивная доска задач:** запуск новых задач с выбором рабочего каталога, исполнителя, модели, уровня рассуждений (reasoning effort) и режима доступа к файловой системе (`read-only` / `workspace-write`).
* 🤝 **Команды агентов:** последовательный конвейер, цикл автор → критик → редактор до одобрения, параллельный консилиум с синтезом и автономный тимлид; типизированные артефакты и продолжение с упавшего шага.
* 🎭 **Сотрудники:** конструктор кастомных агентов — роль, цель, характер, формат результата, модель из каталога, внешность, MCP и тонкие настройки.
* 🧭 **Единый каталог моделей:** модели всех установленных CLI в одном списке — ничего не нужно вводить вручную.
* 🛡️ **Встроенный Agentic Shield:** превентивная защита от Path Traversal, экранирование межсессионных сообщений, фильтрация инъекций и предотвращение утечек секретов.

## ⚡ Быстрый старт

### Системные требования
* **Node.js 24+** и npm.
* Установленный и авторизованный CLI хотя бы одного провайдера (**Claude Code**, **OpenAI Codex** или **Google Antigravity `agy`**).
* ОС: **Windows 10/11**, **macOS** или **Linux**.

### Запуск за 2 шага

```bash
# 1. Установка зависимостей монорепозитория
npm ci

# 2. Запуск демона и веб-интерфейса
npm run dev
```

Откройте офис в браузере: [**http://127.0.0.1:5173**](http://127.0.0.1:5173).

> [!TIP]
> **Пользователям Windows:** в корне проекта доступен ярлык `Открыть офис.cmd`. При первом клике он автоматически установит зависимости, откроет браузер по готовности сервера и поднимет все фоновые службы.

---

### Демонстрационный режим (без моделей и затрат)

Чтобы оценить возможности визуализации или показать проект коллегам без вызова платных API:

```bash
# Демо-режим с анимациями персонажей и симуляцией работы
npm run dev:demo
```

Для полной изоляции доски задач с имитацией выполнения (фейковые CLI с задержкой 6 секунд):

```bash

npm run start -w @land/daemon -- --fake-agents --no-real

# Терминал 2: запуск графической сцены
npm run office
```

## 🗺️ Как читать офис

Каждая активная сессия провайдера представлена сотрудником. Ряд столов соответствует рабочему каталогу проекта, а физическое местоположение персонажа отражает текущий статус:

| Локация в офисе | Что делает агент | Визуальный индикатор |
|---|---|:---:|
| **Рабочий стол** | Пишет код или размышляет над задачей | Анимация за компьютером |
| **Архив** | Читает файлы, просматривает каталоги, ищет по кодовой базе | Читает стеллажи документов |
| **Серверная** | Запускает тесты, скрипты сборки или терминальные команды | Работает у серверных стоек |
| **Интернет-киоск** | Выполняет веб-поиск и документационные запросы | Находится у терминала связи |
| **Доска планов** | Анализирует требования, составляет план шагов | Стоит у маркерной доски |
| **Переговорка** | Передаёт ход коллеге по пайплайну или обсуждает архитектуру | Находится за круглым столом |
| **За столом с «!»** | **Ждёт реакции пользователя** (подтверждение команды, ввод ответа) | Поднятая рука с восклицательным знаком |
| **Кухня / Выход** | Ход завершён: пьёт кофе, отдыхает и покидает офис | Находится у кофемашины |

### Персонализация моделей

Внешний облик персонажа адаптируется под используемую нейросеть:
* 👑 **Claude Opus:** персонаж в королевской короне глубоких рассуждений.
* 🎨 **Claude Sonnet:** характерный берет создателя и исследователя.
* 📓 **OpenAI GPT Sol / Codex:** персонаж с рабочим блокнотом и карандашом.
* 🪐 **Google Antigravity:** персонаж со спутником на персональной орбите.

### Постоянные жители офиса: Макс, Расул и Ваня

В офисе постоянно присутствуют трое штатных обитателей. Они живут по полностью детерминированным локальным поведенческим сценариям (без обращения к LLM и сети), разбавляя рабочую обстановку:
* 🛴 **Макс:** катается на самокате, полирует лысину, танцует, пьёт эспрессо и снимает корпоративный влог.
* 🤹 **Расул:** жонглирует, разряжает обстановку мемами, пародирует коллег и попадает в забавные неловкие ситуации.
* 🏋️ **Ваня:** достаёт из кармана гантель, делает подходы на бицепс, разминается и читает литературу между сетами.

Жители умеют объединяться в парные и тройные совместные сценки (пародии, тренировки, мем-брейки) и мгновенно откликаются на клик мыши дружелюбным приветствием.

## 🛠️ Доска задач и разговоры

Откройте вкладку **«Разговоры»** в боковой панели или нажмите кнопку **«+ Новая задача»**:

1. **Выбор проекта:** выберите путь из недавних, откройте системный обзор или введите абсолютный путь к папке репозитория.
2. **Параметры запуска:** исполнитель (Claude, Codex, Antigravity), модель из каталога, уровень рассуждений (список подстраивается под модель) и доступ (`Только чтение` / `Может править`).
3. **Живой вывод:** пока задача работает, вывод CLI приходит по WebSocket порциями раз в 60 мс и показывается в сворачиваемом блоке «Вывод CLI» — отдельно от ответа.
4. **Ответ целиком:** ответ не обрезается (захват вывода CLI — 400 000 символов по умолчанию, до 2 000 000 в «Настройках»). Кнопки **«Копировать»**, **«Скачать .md»** и **«Сохранить в проект…»**; путь сохранения проверяется — выйти за папку проекта нельзя.
5. **Непрерывность диалога:** ответ агенту продолжает ту же сессию CLI и остаётся в том же разговоре; новая задача всегда открывает новый.
6. **Разговоры:** переименование (✎), закрепление вверху списка, экспорт всей истории в Markdown, шкала заполнения контекста; у каждого разговора свой черновик и своя позиция прокрутки.

Одновременно выполняется до 3 задач (1–8 в «Настройках»), в одной папке — не больше одной задачи с правом записи. Если CLI долго ничего не выводит, у задачи появляется пометка: возможно, он ждёт подтверждения или завис.

## 🤖 Сотрудники и каталог моделей

### Модели: только выбор из списка

Демон собирает единый каталог моделей всех установленных CLI: **Claude** (встроенный список, алиасы `opus` / `sonnet` / `haiku`, модели из `~/.claude/settings.json`), **Codex** (`~/.codex/models_cache.json` и `config.toml` с уровнями рассуждений) и **Antigravity** (`agy models`). Во всех формах модели сгруппированы по CLI; выбор модели из любой группы сам подставляет провайдера, а «Уровень рассуждений» показывает только поддерживаемые моделью значения. Кнопка **↻** пересканирует CLI. Для локального прокси последний пункт списка — «Указать кастомный ID модели…» (допускается только простой идентификатор, который нельзя принять за флаг CLI).

### Конструктор сотрудника

Вкладка **«Сотрудники»** → **«＋ Создать сотрудника»**:

* **Роль, цель, характер и формат результата** (схема CrewAI): Писатель, Критик, Редактор, Архитектор, Кодер, Безопасник или своя роль; шаблоны заполняются в один клик.
* **Провайдер и модель, уровень рассуждений, доступ**, внешность (цвет одежды и аксессуар с живым превью) и набор MCP.
* **Тонкие настройки работы:** стиль мышления, бюджет контекста и стратегия переполнения, автоповторы 0–3, тайм-аут шага, разрешённые и исключённые пути, флаги CLI только из разрешённого списка.

На карточке — «Поручить задачу», «В команду», «Изменить», «Дублировать», «Экспорт» (JSON); клик по карточке показывает сотрудника на сцене. Профили хранятся в `~/.land/agents.json`; персоны Agent Studio из 1.3–1.4 при первом запуске 1.5 переносятся автоматически, исходный файл остаётся в `agents.json.v1.4.bak`.

### Стек обязательных MCP

Четыре MCP применяются к каждой задаче и к каждому шагу команды:
1. 📄 **`markitdown`:** вложения .docx, .pdf, .epub, .xlsx, .html, .md и .txt — в чистый Markdown.
2. 📊 **`context-budget`:** подсчёт символов и токенов промпта, истории и вложений; шкала заполнения в разговоре.
3. 🗜️ **`strategic-compact`:** сжатие промежуточного контекста с сохранением имён, заголовков и сигнатур кода.
4. 🛡️ **`agentic-shield`:** блокировка опасных команд и выхода за папку проекта, маскирование ключей, пометка косвенных prompt injection.

Меню **«MCP»** в шапке показывает статус точками (зелёная — активен, янтарная — не установлен, синяя — идёт установка) и ставит недостающее в один клик. Собственные MCP land.inc ставятся офлайн из локального пакета в `~/.land/mcp-runtime/`; MarkItDown — из PyPI по запросу.

## 🤝 Команды в «Переговорке»

Команда — граф шагов: каждый шаг выполняет отдельный CLI и выдаёт **типизированный артефакт** (спецификация, дифф, отчёт проверки, аудит безопасности, план или черновик главы, критика, вычитанная рукопись). Шаги собираются из сотрудников или настраиваются вручную, модель — из каталога.

| Режим | Как работает |
|---|---|
| **Последовательный конвейер** | Шаги по очереди; каждый получает артефакты предыдущих |
| **Цикл с рецензированием** | Автор → критик → редактор (или снова автор), пока критик не напишет `ВЕРДИКТ: APPROVED`; 1–5 итераций |
| **Параллельный консилиум** | Участники решают задачу одновременно, последний шаг — синтезатор |
| **Автономный тимлид** | Тимлид делит задачу, специалисты работают параллельно, тимлид собирает итог |

```text
  Claude · Автор ──ChapterDraft──▶ Codex · Критик ──NEEDS_REVISION──▶ Antigravity · Редактор
        ▲                                │                                   │
        │                           APPROVED → итог                          │
        └──────────── контрольная точка после каждого шага ◀────────────────┘
```

* **Якорь команды:** неизменяемые факты (имена персонажей, сюжет, инварианты API) передаются каждому шагу.
* **Конверт с данными:** артефакты коллег передаются как данные, а не инструкции; следующий агент проверяет конверт перед работой. Артефакты больше 6 000 символов передаются файлом из `<проект>/.land/artifacts/` (папка исключена из git), чтобы длинная глава доходила целиком.
* **Контрольные точки:** команду, упавшую из-за сети или лимита CLI, остановленную вручную или прерванную перезапуском демона, можно продолжить кнопкой **«Продолжить с шага N»**, при необходимости сменив модель или CLI этого шага. Готовые шаги не перезапускаются.
* **Пресеты:** «Книжное бюро», «Конвейер кода», «Консилиум», «Автономный тимлид» и свои — «Сохранить как пресет».
* **На сцене:** над работающим участником — баббл с этапом («Пишет главу…», «Проверяет логику…»), передача хода показывается анимацией.

Запуски хранятся в `~/.land/team-runs.json`, пресеты — в `~/.land/presets.json`.

### Совместная работа (классический режим)

В форме новой задачи можно включить «Совместную работу»: планировщик, исполнитель, до 20 проверяющих и завершающий ход исполнителя. Ответ каждого хода сохраняется полностью в `<проект>/.land-workspace/<id>/`, коллегам передаётся раздел «## Коллеге» как данные. История последних 30 команд — в `~/.land/teams.json`.

## 🛡️ Безопасность и Agentic Shield

Архитектура land.inc построена по принципу минимальных привилегий:

### 1. Санитизация путей и защита от Path Traversal
Метод `sanitizeWorkspacePath` исключает выход за границы рабочей папки:
* Пресекаются переходы по относительным путям `..` и манипуляции с разделителями.
* Заблокирован доступ к корням системных дисков и критическим системным директориям (`C:\Windows`, `C:\Program Files`, `/etc`, `/usr`, `~/.ssh`, `~/.aws`, `~/.gnupg`).
* Проверяются и блокируются символические ссылки, указывающие наружу проекта.

### 2. Сессионная аутентификация и изоляция Origin
* WebSocket и HTTP API требуют криптографический сессионный токен, который демон создаёт при запуске и держит только в памяти. Офис получает его запросом `GET /token`, доступным лишь с доверенного `Origin`; токен можно сменить в «Настройках», после чего все подключения переподключаются.
* Без токена открыты только `/health` и `/hook` (хуки Claude Code; тело не больше 256 КБ).
* Проверяется заголовок `Host: 127.0.0.1:4317` и список доверенных браузерных `Origin`. Все ответы отдаются с заголовками `Content-Security-Policy`, `X-Content-Type-Options` и `X-Frame-Options`.

### 3. Redactor секретов и Prompt Injection Defense
* Ключи OpenAI (`sk-...`), GitHub PAT (`ghp_...`), AWS (`AKIA...`) и приватные ключи маскируются в промптах, ответах и живом выводе CLI.
* Межагентные сообщения проверяются на ключевые паттерны спуфинга и перезаписи системных инструкций (`ignore previous instructions`, `system override`).

### 4. Супервизор процессов и Hang Detector
* `ProcessSupervisor` завершает всё дерево процессов CLI при отмене задачи, остановке команды и выходе демона (`taskkill /T /F` на Windows); частичный ответ сохраняется.
* `HangDetector` замечает CLI, который долго ничего не выводит, и помечает задачу: возможно, он ждёт подтверждения или завис. Процесс при этом не убивается.

### 5. Атомарное хранилище
* Все файлы `~/.land/` пишутся атомарно (временный файл и переименование, очередь записи) с копией `.bak`; повреждённый JSON восстанавливается из неё при запуске.

## ⚙️ Настройки и Doctor

Кнопка **⚙** в шапке или вкладка **«Настройки»**:

1. **Общие и интерфейс** — тема, масштаб, 30/60 FPS и энергосбережение в фоне, режим жителей офиса, звук и браузерные уведомления о завершении.
2. **Провайдеры** — найденные пути `claude`, `codex`, `agy` (включая глобальные папки npm, даже если их нет в PATH), ручное переопределение пути, обновление каталога моделей.
3. **Стек MCP** — включение, статус, порог сжатия контекста.
4. **Команды** — лимит одновременных задач, папка артефактов, автосохранение черновиков, лимит захвата вывода CLI.
5. **Безопасность и Doctor** — Agentic Shield, смена токена, экспорт и импорт `land-backup-v1.5.json`, очистка кеша и **«Проверить систему»**: Node.js, демон (время работы, память, CLI-процессы), права на `~/.land`, каждый CLI, каталог моделей, MCP, свободное место и доступность сервисов провайдеров — с кнопкой «Исправить автоматически», где это возможно. Тот же отчёт из терминала: `node apps/daemon/src/doctor.ts`.

## 🌐 Настройка DNS в Windows

Вкладка **DNS** решает проблему нестабильного доступа к API зарубежных провайдеров из-за блокировок и сбоев провайдерских резолверов:

1. **Выбор адаптера:** просмотр активных физических и виртуальных сетевых интерфейсов.
2. **Диагностика без изменения системы:** кнопка «Проверить DNS» выполняет серию прямых контрольных DNS-запросов к серверам Anthropic, OpenAI и Google, оценивая пинг и корректность ответов.
3. **Безопасное применение:** системный помощник запускается через UAC с подтверждением администратора. Сам демон от имени администратора **не запускается**.
4. **Транзакционный откат:** перед любым изменением исходная конфигурация адаптера (DHCP или статические IP) бэкапится в `~/.land/dns-backups.json`. В случае ошибки или по кнопке «Восстановить прежние настройки» параметры возвращаются в исходное состояние.

## 📦 Обновления в один клик

land.inc включает встроенный механизм бесшовного обновления:
* Демон периодически проверяет GitHub Releases репозитория.
* При появлении новой версии у входа в офис появляется визуальная **посылка с зелёной лентой**.
* По нажатию «Установить» создаётся изолированная копия релиза в каталоге `.land-updates`, проверяется SHA тега, ставятся зависимости, прогоняются тесты и выполняется атомарное переключение без риска повредить исходный Git-репозиторий.
