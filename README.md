# land.inc

2.5D офис для AI-агентов (вид сверху). Агенты ходят по офису, сидят за компьютерами, общаются друг с другом,
а офис живёт синхронно с реальными сессиями **Claude Code / Claude Desktop** и **Codex**, которые запущены на этом компьютере.

Никаких API-ключей: офис только читает локальные файлы, которые агенты и так пишут на диск.

## Запуск

Нужен Node.js 24+ (демон запускается из TypeScript без сборки).

```bash
npm install
npm run dev        # демон + офис → http://127.0.0.1:5173
npm run dev:demo   # то же самое плюс демо-агенты, которые проходят по всем зонам
```

## Как работает синхронизация

| Источник | Где лежит | Что даёт |
|---|---|---|
| Claude Code (CLI, IDE, вкладка Code в Claude Desktop) | `~/.claude/projects/<project>/<session>.jsonl`, сабагенты в `<session>/subagents/*.jsonl` | Транскрипт в реальном времени: промпты, ответы, вызовы инструментов, `stop_reason` |
| Codex (CLI и Codex Desktop) | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` + индекс тредов в `~/.codex/state_*.sqlite` | Сообщения, вызовы команд, `task_complete`, запросы разрешений |
| Хуки Claude Code (опционально) | `~/.claude/settings.json` | Мгновенный сигнал «ждёт вашего разрешения» (`Notification`) |

`apps/daemon` опрашивает эти файлы, читает только дописанные байты и превращает записи в общий поток событий
(`packages/protocol`). Клиент `apps/office` получает его по `ws://127.0.0.1:4317`.

Демон слушает только loopback, принимает запросы только с `Host: 127.0.0.1:<порт>` (защита от DNS rebinding)
и пускает браузер только с разрешённых `Origin`, чтобы посторонний сайт не мог прочитать транскрипты.

По умолчанию браузерный доступ разрешён с `http://127.0.0.1:5173` и `http://localhost:5173`. Для другого адреса
клиента задайте демону `LAND_ALLOWED_ORIGINS` — список полных origin через запятую. Доверяйте только приложениям,
которые должны иметь доступ к журналам. Локальные процессы без `Origin` (хуки, `curl`) могут обращаться к HTTP API;
WebSocket всегда требует разрешённый `Origin`.

Треды, которые Codex Desktop импортировал из других агентов, скрываются: такой файл записан целиком за миллисекунды.
Если продолжить импортированный тред в Codex, его агент появится в офисе.

### Хуки для мгновенных статусов (опционально)

Без хуков «ждёт разрешения» определяется эвристикой: вызов инструмента висит дольше 12 секунд без результата.
С хуком Claude сразу сообщает об этом офису. Добавьте в `~/.claude/settings.json`:

```json
{
  "hooks": {
    "Notification": [
      { "hooks": [{ "type": "command", "command": "curl -s -m 1 -X POST --data-binary @- http://127.0.0.1:4317/hook || true" }] }
    ]
  }
}
```

Демон также понимает `UserPromptSubmit`, `PreToolUse`, `PostToolUse` и `Stop` на том же адресе.

## Что видно в офисе

- **Сессия = сотрудник.** Цвет рубашки: оранжевый у Claude, зелёный у Codex, фиолетовый у демо-агентов.
  Сабагенты поменьше и связаны с родителем пунктиром.
- **Модель = персонаж.** Модель берётся из каждой записи транскрипта (`message.model` у Claude,
  `turn_context.model` и `effort` у Codex), поэтому смена модели посреди сессии тоже видна. На табличке
  указаны модель и уровень рассуждений, например «Sonnet 5.5 · medium».

| Модель | Персонаж |
|---|---|
| Opus | корона и фиолетовый плащ |
| Sonnet | берет и шарф |
| Haiku | поменьше, росток на макушке |
| Fable | синий колпак со звездой |
| GPT Sol | карандаш за ухом, блокнот, значок-солнце |
| GPT Terra | бандана и рабочий фартук |
| GPT Luna | ночной колпак с луной |
| GPT Astra | антенна со звездой |
| Codex Auto Review | маленький инспектор с лупой: служебная проверка, а не отдельный работник |

- **Эмоции.** Ярость печати при правках, круглые очки в архиве, пот и «!» при ожидании разрешения,
  лампочка над головой, если команда идёт дольше 20 секунд, «zzz» после двух минут на кухне.
  Тёмные очки появляются на полторы минуты после зелёных тестов, слёзы — после красных.
- **Проект = ряд столов.** Сессии одного репозитория садятся рядом.
- **Действие → место:**

| Активность | Инструменты | Где агент |
|---|---|---|
| думает / пишет код | reasoning, `Edit`, `Write`, `apply_patch` | свой стол (монитор синий / зелёный) |
| читает | `Read`, `Grep`, `Glob`, `cat`, `rg`, `git log`… | архив |
| запускает команды | `Bash`, `PowerShell`, `shell` | серверная (стойки мигают) |
| ищет в сети | `WebSearch`, `WebFetch`, браузер | интернет-киоски |
| планирует | `TodoWrite`, `update_plan` | доска планов |
| делегирует | `Agent` / `Task`, `spawn_agent` | переговорка |
| ждёт вас | запрос разрешения, вопрос | свой стол, поднятая рука и «!» |
| закончил ход | `end_turn`, `task_complete` | кухня |

Сессия без активности 45 минут уходит домой через дверь. Клик по агенту или строке в списке показывает журнал
его последних действий. Камера: перетаскивание, колесо мыши для зума, двойной клик возвращает общий вид.

## Доска задач

Пробковая доска «ЗАДАЧИ» на левой стене или вкладка «📌 Задачи» в боковой панели. Выберите папку проекта
(из недавних сессий или любую другую), исполнителя, модель, уровень рассуждений и доступ, затем опишите задачу.
Демон запустит CLI агента в этой папке. Работник войдёт в офис через дверь со значком 📌, а его ответ появится
в карточке задачи.

| | Claude | Codex |
|---|---|---|
| CLI | `claude.exe` из Claude Desktop (или `claude` в PATH) | `codex.exe` из Store-пакета Codex Desktop (или `codex` в PATH) |
| Модели | Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1 | из `~/.codex/models_cache.json`, кроме скрытых |
| Только чтение | `-p --permission-mode plan` | `exec --sandbox read-only` |
| Может править | `-p --permission-mode acceptEdits` | `exec --sandbox workspace-write` |

Спросить разрешения в фоновом запуске некому. Поэтому у Claude всё, что требует подтверждения (включая команды
терминала), отклоняется, а Codex запускается с `approval_policy="never"`: всё за пределами песочницы
отклоняется. Одновременно выполняется не больше 4 задач. История хранится в `~/.land/tasks.json`.
Задачи принимаются только по WebSocket от разрешённого `Origin`, а модель и уровень рассуждений
проверяются по списку, прежде чем попасть в командную строку.

Встроенный в Claude Desktop `claude.exe` авторизован только внутри сессий Desktop. Для фоновых задач
войдите один раз сами: доска покажет точную команду вида `& "<путь>claude.exe" auth login`.
Codex использует вход Codex Desktop.

## Структура

```
apps/daemon        # наблюдатель за файлами + WebSocket-сервер (Node, TypeScript без сборки)
  src/adapters/    # claude.ts, codex.ts — разбор форматов каждого агента
  src/store.ts     # состояние агентов и переходы по времени (простой, ожидание, уход)
  src/tasks.ts     # доска задач: поиск CLI, моделей и папок, запуск и учёт задач
apps/office        # клиент на PixiJS: изометрическая сцена, агенты, боковая панель
  src/character.ts # персонажи по моделям и их эмоции
  src/board.ts     # панель доски задач
packages/protocol  # общие типы событий
```
