# land.inc

2.5D офис для AI-агентов (вид сверху). Агенты ходят по офису, сидят за компьютерами, общаются друг с другом,
а офис живёт синхронно с реальными сессиями **Claude Code / Claude Desktop** и **Codex**, которые запущены на этом компьютере.

Никаких API-ключей: офис только наблюдает за локальными данными агентов.

## Как работает синхронизация

| Источник | Где лежит | Что даёт |
|---|---|---|
| Claude Code / вкладка Code в Claude Desktop | `~/.claude/projects/<project>/<session>.jsonl` | Транскрипт в реальном времени: промпты, ответы, вызовы инструментов, сабагенты |
| Хуки Claude Code | `~/.claude/settings.json` → `hooks` | Мгновенные события: `SessionStart`, `PreToolUse`, `PostToolUse`, `Notification`, `Stop` |
| Codex (CLI / App) | `~/.codex/*.sqlite`, `~/.codex/sessions/**/rollout-*.jsonl` (зависит от версии) | Потоки, сообщения, вызовы команд |
| Хуки / `notify` в Codex | `~/.codex/config.toml` | Событие о завершении хода |

Демон `land-daemon` следит за этими файлами, нормализует их в общий поток событий и отдаёт их через
`ws://localhost:<port>` в клиент офиса.

## Модель отображения

- **Сессия → агент.** Один персонаж на сессию; сабагенты появляются как «стажёры» рядом с ним.
- **Проект (cwd) → комната / отдел.** Сессии в одном репозитории сидят в одной комнате.
- **Вызов инструмента → анимация:** `Read`/`Grep` = идёт к стеллажу с книгами, `Edit`/`Write` = печатает,
  `Bash` = серверная, веб-поиск = окно / библиотека, ожидание разрешения = поднятая рука над головой.
- **Ожидание пользователя → кофе-машина / диван.** Закрытая сессия — агент уходит из офиса.
- **Общение:** сабагент или сообщение между сессиями = агенты подходят друг к другу, над ними появляется облачко.

## Планируемый стек

- Клиент: TypeScript + PixiJS (изометрический тайлмап), позже обёрнут в Tauri как приложение / оверлей.
- Демон: Node.js (`chokidar` для файлов, `better-sqlite3` в режиме только для чтения для Codex, WebSocket).
- Общий формат событий: `packages/protocol`.

## Структура (план)

```
apps/office     # клиент на PixiJS
apps/daemon     # наблюдатель за файлами + WebSocket-сервер
packages/protocol
packages/adapters/claude
packages/adapters/codex
```
